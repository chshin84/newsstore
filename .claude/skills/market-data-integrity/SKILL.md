# market-data-integrity — 받은 숫자를 의심하라

> **핵심 명제**: 데이터를 **받는 것**과 **이해하는 것**은 다른 작업이다. 검증 없는 수집은 출처 불명의 숫자를 쌓는 것일 뿐이다. 에러는 시끄러워 잡기 쉽지만, **조용히 틀린 데이터**는 검문소를 세워야만 잡힌다(코드는 멀쩡히 돌고 파일도 생기는데 내용만 틀림). newsstore가 실제로 겪은 KS200 ±10% 오답·라이브vs stale·휴장 null이 전부 이 부류다.

## 언제 (트리거)
가격/지수/환율/종목 데이터를 수집·파싱·저장·교차검증하거나, **새 데이터 소스**(Yahoo 외 FDR·pykrx·ECOS 등)를 추가할 때. 리포트가 이 숫자 위에 판단을 세우므로 정합성이 곧 리포트 신뢰다.

## 받은 숫자의 5가지 함정 (의심 목록)
1. **수정주가 vs 원주가** — 액면분할·배당을 소급 보정한 게 수정주가. 원주가로 등락률을 내면 5:1 분할이 **−80% 폭락**으로 찍혀 멀쩡한 자산에 폭락 경고가 뜬다. 추세·등락률 대시보드는 **수정주가 기준**. 라이브러리가 알아서 한다고 믿지 말고 분할 이력 종목으로 전후 차트가 매끄러운지 확인.
2. **지연시세** — 무료 시세는 대개 15~20분 지연. 매시각 갱신엔 무해하나, **지연을 실시간으로 착각해 표시**하면 잘못된 시점 판단. 해법: **조회 시각(fetch-time)을 함께 저장·표시**("몇 시 기준"). newsstore 실측: 뉴스 아이템엔 `fetched_at`이 있으나 **가격 doc엔 `datetime`(데이터 날짜)만 있고 조회시각이 없다** → 신선도 검문 불가(갭).
3. **결측·휴장일** — 일봉엔 주말·공휴일이 없는 게 정상. **KR≠US 휴장일**이라 코스피·나스닥을 날짜기준 없이 옆으로 붙이면 조용한 어긋남. 진짜 결측(거래정지·수집실패)은 **에러를 안 낸다** — 20일 이동평균이 실제론 17일치로 계산돼도 조용히 돈다. → **날짜 인덱스 기준 결합**, 빠진 날짜 대조 필수.
4. **상장폐지·생존편향** — 오늘 종목 리스트로 과거를 조회하면 살아남은 종목만. 과거 통계엔 그 시점 명단이 필요.

## 검산 4검문소 (수집에 항상 붙인다)
1. **교차검증** — 같은 값을 **두 경로**로 받아 오차율(%) 비교(절대차 아님 — 지수 0.5p와 환율 0.5원은 무게가 다름). >0.1%면 사람이 제3기준으로 확인. 검문소는 "의심 지점 있다"고 손드는 것까지, 정답은 안 준다.
2. **상식 범위 플래그** — 등락률이 상식 밖이면 깃발(지수 ±15%·환율 ±5%·종목 ±30% 가이드). **삭제 말고 플래그만** — 검증≠수정. 지우면 진짜 폭락장 데이터를 오류로 오인해 지우는 더 큰 사고. (newsstore KS200 −10% 오답이 정확히 이 검문소 부재.)
3. **빠진 날짜 감지** — "있어야 할 거래일 달력"(다른 경로/거래소 집계) vs "받은 날짜" 집합 빼기. missing/extra를 사람 일감으로. 양쪽이 똑같이 빠뜨린 건 못 잡음 → 통과=무죄확정 아니라 "현 검사로 이상없음".
4. **신선도** — `fetched_at` age 검사. 자동수집의 가장 흔한 장애는 값 오류가 아니라 **수집이 조용히 멈추는 것**(스케줄러 죽으면 화면은 낡은 파일을 태연히 표시). 마지막 거래일 기준으로 판정(주말·휴장 오탐 회피).

→ 결과를 **성적표(status)**로 남긴다 — 안 보는 화면의 print 경고는 없는 경고. UI에 "검사 통과" 배지로 신뢰 표식.

## 불변식 (원칙)
- **검증 ≠ 수정**: 코드는 깃발만 꽂고, 처분(삭제·보정)은 사람이. (newsstore `비파괴 우선`과 동일 — 삭제 말고 표시.)
- **문턱값에 정답은 없다** — 없다는 이유로 검문소를 안 세우는 것과 보수적 문턱이라도 세우는 것 사이엔 사고 한 번 분량 차이. 매직넘버가 아니라 자산 체질별 가이드(불변식으로 테스트).
- **무료 소스 = 품질보증 내 몫**: 기관은 돈으로, 우리는 검산 코드로 품질을 만든다.

## newsstore 매핑 (이미 함 / 갭)
- **이미 함**: 가격 교차검증(뉴스 vs 실제 가격, `report.price_context`)·fail-loud(768 패리티 등)·null 드롭(휴장 close)·값·등락 시계열 일관 도출(라이브vs stale 사고 후)·`fetched_at`·리포트 갱신지연 상태.
- **갭(개선 후보 — 이 스킬이 가리키는 곳)**: ① **상식범위 플래그**(가격 %등락에 없음 — KS200 ±10% 버그 재발 방지) ② **데이터소스 교차검증**(현재 Yahoo 단일 — KR 지수를 pykrx로 2경로 대조) ③ **빠진날짜/gap 감지**(move_detector 베이스라인 표본에 명시 없음) ④ **데이터 정합성 배지/status**(divergence·conviction은 있으나 데이터-무결성 표식은 없음).

## 소스 지형도 (신규 소스 검토 시)
- **무료 라이브러리**: Yahoo(무키, 현 사용)·FinanceDataReader(국내외 지수·환율·코인 단일 인터페이스, 수정주가 기본)·**pykrx**(KRX 집계 — 시가총액·**투자자별 매매동향**·공매도 = newsstore에 없는 신규 데이터 후보). 무료·무키·검산 필수.
- **증권사 OpenAPI**(KIS·키움): 실시간 근접·주문 가능, 토큰관리 비용. 시황엔 과한 장비.
- **유료 벤더**(블룸버그·에프앤가이드): 기관용. 개인 접점 없음.

*(스킬 밖: Streamlit·윈도우 작업 스케줄러 — newsstore는 web SPA + Cloud Run Jobs/Scheduler라 해당 챕터는 스택 불일치로 제외.)*
