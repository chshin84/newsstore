# Spec W_web (Round 1) — 리포트 UI v2 (서브섹션·글로벌 숨김·프레임·순서·사이드바 트리)

작성: 2026-07-05 · 개정(fork 확정·리뷰 반영·사용자 추가지시) · 구간 소유권 = `web/index.html` + `tests/web/*`만. **백엔드(`src/`·`config/`) 금지**(W_backend 병렬). 리포트 **섹션 스키마·프레임 극 shape 불변**(표시만).

## 확정 맥락
프레임 fork="2층"(Round 2 백엔드), 글로벌 fork="**화면만 숨김**"(`_market` 생성·주입은 백엔드 유지 → web은 박스만 안 그린다). 이 스펙은 결정론 UI만.

## 작업

### WW1. 서브섹션 정리 (주시·미발생 최하단·기본숨김·펼치기) — 사용자 재강조
- 아킬레스(risk_triggered)·기대(premium_triggered)는 **상단 유지**. **주시(watchpoints)·미발생(not_triggered)은 렌더 최하단으로 내리고 기본 숨김 + '펼치기' 토글.** 특히 **미발생을 가장 아래로.** 섹션 스키마·데이터 불변, 표시 순서·접힘만. SEC_LABEL(~1093)·렌더 루프(~1153) 대상.

### WW2. 글로벌 프레임 화면만 숨김 (백엔드 무변경)
- web `.mktframe` 블록(~1176-1181)·토글 핸들러(~1231)·전용 CSS(~258-285) 제거 → 박스 안 보임. **백엔드 `_market` 생성·자산 프레임 주입은 그대로**(fork 확정 — 분석 손실 없음). `docm.backdrop`은 백엔드가 계속 쓰므로 데이터는 유지, web 표시만 제거.

### WW3. 프레임 보기 위치 + 글자색 제거
- "프레임 보기"(`.rframe`, ~1160)를 **섹션 본문 뒤에 배치** — 구체적으로 **아킬레스·기대(트리거 서브섹션) 뒤, WW1에서 최하단 숨김된 주시·미발생 블록 앞**(리뷰 지적한 상대위치 명시). 펼침 동작 유지.
- **프레임 글자색 제거** — `frameChipsHtml`/`.fchips`의 risk/imp/green **글자색을 중립으로**. 단 risk/premium/watch는 의미가 상반돼 **구분이 본질적으로 필요** → 색 대신 **대체 신호(라벨·아이콘)를 의무화**(리뷰 지적 — 선택 아님). 접근성·변별 유지.

### WW4. 순서 — 급부상 최상단 + "rising" 글자 제거 — 사용자 추가지시
- `assembleReportDoc`(~732)에서 **급부상을 맨 위**로(현재 첫 그룹 뒤 → 최상단). 그 아래는 그룹 순서(=W_backend가 topics.yaml 조정: 주식→금리·채권→나머지)를 docm.sections대로.
- **UI에 "rising" 글자가 보이지 않게, "급부상"만 노출.** 내부 lensId="rising"은 유지하되 사용자 노출 라벨·앵커 텍스트는 "급부상"으로 통일(현재 group="급부상"이나 "rising"이 새어나오는 곳 있으면 제거). 딥링크·스크롤스파이 유지.

### WW6. 리드 → 불릿 렌더 (핵심 합성) — 사용자 확정
- 현재 산문 `.dlead`(~1165, report.lead)를 **불릿 목록으로 렌더**(사용자 "읽기 힘들다 → 불릿"). W_backend가 `lead`를 **짧은 문자열 배열(≤3)**로 산출(frozen 계약).
- **하위호환(graceful)**: `lead`가 배열이면 불릿, 문자열(구형·배포 순서차)이면 산문 폴백 — 배포 순서 무관하게 안 깨지게. Spec B 2줄 클램프는 불릿엔 부적합하니 불릿용 표시로 대체. 짧아 스캔 가능하게.

### WW5. 사이드바 디렉토리 트리 + 선택 표식 재디자인 — 사용자 재강조
- 사이드바를 **계층 트리(하위 디렉토리 은유)**로. **피드는 사이드바에서 제거**(헤더 탭·피드 뷰는 유지, 목록에서만). 스토리 그대로. 리포트 목차는 **`.navgroup` 중간 헤더 없애고 렌즈 바로 나열**(한국 주식·미국 주식…, 순서=docm.sections). 자식 있는 항목은 폴더처럼 펼침/접힘.
- 선택 표식 **신선하게 재디자인** — **왼쪽 색막대 재사용 금지**(카드 컴포넌트 모티프), **Spec B 카드 색점과도 시각 충돌 없게**(도트 택하면 카드 색점과 구분되게). `.navlink.active`뿐 아니라 **`.navtab.active`의 좌측막대도 함께 마이그레이션**(옛 표식 잔존 금지). 스크롤스파이 하이라이트도 새 표식. **frontend-design 스킬로 접근**, 택한 근거를 보고에 명시.
- **persistence 일관**: 트리 폴더 펼침(localStorage)과 WW1 주시/미발생 펼치기의 지속 규칙을 **일관되게**(둘 다 localStorage 또는 둘 다 세션 — 리뷰 지적). 하나로 통일.

## 통합/배포 (오케스트레이터가 머지 후)
- node 웹테스트 GREEN. Playwright: 미발생 최하단·숨김/펼치기, 글로벌 박스 부재, 프레임 보기 트리거 뒤·글자색 없음·대체신호 있음, 급부상 최상단·"rising" 글자 없음, 사이드바 트리·피드부재·목차 평면·새 선택표식(옛 좌측막대 잔존 0)·딥링크·모바일·레이아웃 안 흔들림. Hosting 재배포(전체 스냅샷).

## 범위 밖
백엔드(W_backend): 짤림·config 순서. 2층 프레임(Round 2). divergence/conviction 계산. 섹션 스키마 재편.

## 리스크/주의 (주입 gotchas)
- 순수함수는 REPORT-LOGIC 마커 안(node 테스트). **사이드바 평면화·순서·서브섹션 재배치 로직은 순수 seam으로 빼 node 테스트**(DOM은 Playwright) — 리뷰 지적한 seam 보장.
- **SSOT**: 순서·목차는 `docm.sections`·meta에서 도출. UI 순서 규칙은 (1)급부상 최상단 (2)주시·미발생 최하단 **두 개**로 명시(하드코딩 복제 아님).
- **Spec B 레이아웃 불변식 보호**: `--side-w`(SSOT)·`.side-ghost`(헤더/본문 중심 정렬)를 트리 작업이 **깨지 말 것**(sidenav 폭을 auto로 바꾸면 흔들림 재발 — flex:0 0 고정폭 유지). scrollbar-gutter·근거 dedup lazy fetch·A필드(divergence/conviction) graceful 유지.
- 딥링크(`#rep-*`·`#story-*`)·스크롤스파이·모바일 드로어·`sideToggle` 회귀 0. 모바일 overflow-x 금지. **DB·문서 불변(표시만)**. Hosting=전체 스냅샷(index.html+config.js). 머지·배포는 오케스트레이터(브랜치까지만).
