# Spec B — 리포트 UI 정리 (사이드바·레이아웃·근거 dedup·군더더기 제거)

작성: 2026-07-05 · 구간 소유권 = `web/index.html` + `tests/web/*`만. **백엔드(`src/`·`config/`) 금지**(#8b가 병렬로 소유).
근거 = 사용자가 라이브 화면에서 짚은 실제 결함 + 선검토. 리포트 **구조(섹션 스키마)는 안 바꾼다**(그건 #4, 2단계).

## 목표
관측된 UI 결함을 고치고 군더더기를 제거해 리포트를 전문적이고 스캔 가능하게. 현재 리포트 구조 위에서만.

## 배경/맥락 (서브에이전트 주입)
- SSOT(렌즈/그룹=meta/report_groups·LENS_LABELS 도출), Fail-Loud, 비파괴. Hosting=전체 스냅샷(index.html+config.js).
- 웹 테스트: node로 `*-LOGIC-START/END` 마커 슬라이스(순수함수만, `new Function`). 렌더/DOM은 밖. `node --test tests/web/report_logic.test.mjs`.
- 현 구조(grounding): 탭 4개(피드·스토리·리포트·가격). 사이드바(`.sidebar`, `.snav-list`)는 리포트(그룹→렌즈)+스토리만. 리포트 렌더=renderReportDoc: **글로벌 프레임(.mktframe)+다이제스트("지금 시장이 두려워하는 것")+헤드라인+리드(AI요약)+섹션+근거 접이식(.ev-toggle/.ev-body)**. 근거 펼침=인용 스토리의 **멤버 기사 전량**(dedup 없음 — `.ev-cluster` "N개 기사"). 스토리 탭엔 `dedupeMains`(중복 카드 제거) 이미 있음. 섹션 헤더 `.rsec-h`=붉은 왼쪽 테두리(risk).
- 이미 배포(불변): report=자산only, divergence 칩·conviction pill, 사이드바·기사출처 접이식(#6 대상).

## 작업 (각 항목 = 관측된 결함/요청)

### B1. 사이드바 4탭 + 접이식 + 좌상단 토글 (#1·#7)
- 사이드바에 **피드·스토리·리포트·가격** 다 넣기(현재 리포트·스토리만). 각 탭 항목 클릭=해당 탭+앵커.
- **좌상단 토글 버튼**으로 사이드바 열고닫기(데스크톱도 접기 가능). 모바일은 기존 드로어 유지.

### B2. 레이아웃 고정 (#7 — 실제 버그, 원인 실측 먼저)
- 탭 전환 시 헤더("newsstore")·탭 바가 **흔들림**. **원인부터 코드로 규명**(추측 금지) — 리뷰 지적: 사이드바는 데스크톱서 showTab이 토글 안 하니 원인 아님. 유력 원인은 **헤더 `.wrap`(뷰포트 중앙정렬) vs 본문 `.wrap`(사이드바-오프셋 `.layout` 안에서 중앙정렬)의 중심 불일치**, 또는 탭별 세로 스크롤바 유무(gutter). 실제 원인 확인 후 **헤더·탭을 안정 정렬**(예: scrollbar-gutter stable, 헤더도 layout 그리드 안에 정렬)로 탭 바뀌어도 안 움직이게. 모바일 포함.

### B3. 프레임 익스팬드/클로즈 (#3)
- 프레임(아킬레스·기대·주시 극)을 **온디맨드 펼치기**로 볼 수 있게(항상표시 X — B에서 렌즈 반복 제거했던 것). UI상 보기 좋은 위치(리포트 헤더 근처 "프레임 보기" 토글 등). frameChipsHtml 재사용 가능.

### B4. 근거 dedup + 원시 기사 감춤 (#6 — 실제 결함)
- 현재 "근거 N건" 펼치면 스토리의 **멤버 기사 전량(예 254개)을 dedup 없이** 쏟음(스크린샷의 Bloomberg 중복).
- **원시 기사는 DB에만**, 화면엔 **근접 중복(같은/유사 헤드라인) 병합** 후 고유 근거만. **빈도순 상위 컷 금지**(리뷰 지적: 고빈도 소스가 대표를 먹고 저빈도 특종이 묻힘 = 블룸버그 전례). 대신 **헤드라인 정규화 dedup + 출처 다양성 보존**. 표시 수는 매직넘버가 아니라 **dedup 후 고유 개수**(불변식) — 너무 많으면 "더보기"로 접기.
- 스토리 탭의 `dedupeMains` 발상 재사용(같은 사건 대표 묶기). 라벨 명확화: "근거 N건"(=인용 스토리 수)이 254개 원시 기사와 혼동 안 되게(예 "인용 스토리 2 · 대표 기사 6").

### B5. 군더더기 제거 (#2·#8a)
- **다이제스트("지금 시장이 두려워하는 것") 제거** — 전 렌즈 risk_triggered 재집계라 각 리포트와 중복.
- **글로벌 시장 프레임** — 렌즈 반복 아니라 최상단 1회지만, **얇은 한 줄로 축소하거나 접이식**(과한 추가정보). 완전 제거는 재량이나 렌즈 리포트가 커버하는지 확인 후.
- **헤드라인 밑 AI 요약(리드)이 아래 섹션과 반복** — 리드를 **헤드라인 보강 한 줄로 축소**하거나, 섹션과 겹치는 부분 제거.

### B6. 리포트 섹션 비주얼 (#5)
- 붉은 왼쪽 테두리(`.rsec-h`)를 **전문적 도형·색 배치**로. semantic 유지(risk=경고색, premium=기대색, watch=중립) 하되 세련되게(칩/뱃지/아이콘·여백). frontend-design 감각.

## 통합/배포 (오케스트레이터가 머지 후)
- node 웹테스트 GREEN. Playwright: 4탭 사이드바·토글, 레이아웃 안 흔들림(탭 전환), 프레임 펼치기, 근거 대표 소수(254 덤프 없음), 다이제스트 제거, 리드 축소, 섹션 비주얼, 모바일 드로어·딥링크(#rep-*·#story-*).
- Hosting 재배포(전체 스냅샷).

## 범위 밖
- 백엔드·리포트 스키마(#8b·#4). 리포트 **섹션 구조 재편**(#4 — 2단계). divergence/conviction 계산.

## 리스크/주의
- 순수함수는 REPORT-LOGIC 마커 안(node 테스트), 렌더는 밖.
- 레이아웃 고정이 기존 반응형(680px)·`.strip` 가로스크롤 안 깨게. 모바일 사이드바 overflow-x 금지.
- 근거 dedup은 표시만 — DB·스토리 문서 불변. lazy fetch 메모이즈(N+1) 유지.
- A 필드(divergence·conviction) graceful 유지. 딥링크 안 깨게.
