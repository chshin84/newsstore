# 데이터 소스 — newsstore가 받는 모든 데이터

이 문서는 newsstore가 현재 수집하는 데이터의 스냅샷이다. newsstore는 **뉴스 수집 전용**이라 분석·LLM 레이어가 없고, 수집한 원본을 Firestore에 저장한 뒤 임베딩 벡터만 부수적으로 산출한다.

수집 경로는 세 가지다.

- **RSS 피드** — `config/feeds.yaml`에 등록된 공개 RSS를 주기적으로 폴링한다(현재 활성 52개).
- **FMP 뉴스 API** — Financial Modeling Prep의 뉴스 파이어호스 6개 엔드포인트를 하루 한 번 재스캔한다.
- **네이버 검색 뉴스 API** — 키워드별로 한국 뉴스를 검색해 수집한다(현재 11개 키워드).

수집 원칙은 "본문만"이다. 제목과 함께 요약이나 전문이 실제로 오는 소스만 활성화하고, 제목만 오는 헤드라인 전용 피드는 제외한다. 임베딩 품질과 다운스트림 재사용이 본문 유무에 좌우되기 때문이다.

## FMP 뉴스 API

Financial Modeling Prep의 뉴스 파이어호스를 하루 한 번(`poll_minutes: 1440`) 고정 3일 lookback으로 재스캔한다. 커서 없이 매번 재스캔하고 URL 기반 id로 중복을 걸러 멱등하게 적재한다. API 키는 백엔드 전용 비밀로 헤더에만 싣는다.

| 엔드포인트 | 내용 |
|---|---|
| `stock-latest` | 미국 주식 뉴스 |
| `press-releases-latest` | 기업 보도자료 |
| `general-latest` | 종합 금융 뉴스 |
| `forex-latest` | FX 뉴스 |
| `crypto-latest` | 크립토 뉴스 |
| `fmp-articles` | FMP 자체 분석 기사 |

## 네이버 검색 뉴스 API

네이버 검색 API로 키워드별 한국 뉴스를 검색해 수집한다(`poll_minutes: 30`, 요청당 100건, 최신순). 응답의 `originallink`를 우선 URL로 쓰고 없으면 네이버 재작성 `link`로 폴백하며, 제목과 요약의 `<b>` 하이라이트와 HTML 엔티티를 제거한다. 클라이언트 ID와 시크릿은 백엔드 전용 비밀로 헤더에만 싣는다.

키워드 세트는 다음과 같다: 증시(kr_stock), 코스피(kr_stock), 경제(kr_macro), 금리(kr_macro), 환율(kr_fx), 반도체(kr_tech), AI(tech), 2차전지(kr_tech), 부동산(kr_realestate), 유가(commodity), 원자재(commodity).

## 처리 파이프라인

세 경로로 들어온 원본은 같은 파이프라인을 거쳐 `items` 컬렉션에 저장된다.

- **제목 정규화 후 중복 제거** — URL(없으면 제목)로 만든 안정적 id로 같은 기사를 한 건으로 접는다.
- **kind 분류** — 비-LLM 규칙 필터가 스팸(집단소송 보도자료 등)·스포츠·다이제스트를 키워드로 분류해 표시한다. 원본은 지우지 않고 숨김 표시만 한다(비파괴).
- **임베딩** — `kind == story`인 기사를 gemini-embedding-001로 768차원 임베딩한다.
- **`item_vectors` 저장** — 벡터를 원본과 같은 만료 시각으로 저장한다(고아 벡터 방지).
- **60일 TTL** — `items`와 `item_vectors`의 각 문서에 `expire_at`(수집 시각 + 60일)을 걸어 만료시킨다. `feed_state`에는 TTL을 걸지 않는다(폴링 커서가 유실되면 증분 수집이 어긋난다).

## 차단·미작동·제거된 소스

단순 삭제가 아니라 이유를 남긴다. 같은 소스를 다시 시도하거나 대체 경로를 찾을 때 이 기록이 필요하기 때문이다. 아래 발견·정리는 모두 2026-07-19 기준이다.

- **Benzinga (16개 피드)** — 2026년 6월부터 피드 item이 0으로 떨어져 사실상 죽었다. 경로 자체를 폐기하고 활성 목록에서 제거했다.
- **WSJ (5개 피드)** — 클라우드 실행 IP를 차단하는 데다 공개 RSS에 본문 스니펫이 없어 제목만 온다. "본문만" 원칙에 맞지 않아 제거했다.
- **제목 전용 15개 피드** — 응답은 정상이나 per-item 본문이 없어 제목만 오는 피드를 제거했다: 한경 구글뉴스 우회(gn_hankyung), Yahoo Finance, Seeking Alpha, Investing FX(investing_fx), Investing 채권(investing_bond), ECB, Bloomberg 기술·경제·산업(bbg_technology·bbg_economics·bbg_industries), 루머·반도체 구글뉴스(gn_rumor·gn_kr_chips), Reuters 구글뉴스 우회(reuters_top), FT 홈·마켓·경제(ft_home·ft_markets·ft_economy).
- **이전에 주석으로만 남아 있던 19개 후보** — 프로빙에서 HTTP 403·404를 받거나 빈 피드였던 후보들이다. 이번에 config에서 완전히 삭제하고 사유를 이 문서로 옮겼다. 한경 직접 RSS 6종(클라우드 데이터센터 IP 403), 인포맥스 기고 섹션(빈 피드), Benzinga 스몰캡(빈 피드), BIS 보도자료·BLS·NBER·IMF·CFR·IEA·OPEC·Kitco·KCIF·한국은행·Bloomberg 그린 등이 여기에 해당한다.
- **FMP 뉴스** — 코드는 있었으나 수집 Job이 배포되지 않아 한동안 0건이었다. 이제 Job이 배포되어 수집된다.

한경 본문 스크랩(hankyung.com `.article-body` 셀렉터)도 한경 소스가 사라지면서 함께 비활성화됐다. 본문 스크랩이 필요한 소스가 다시 생기면 `body_fetch.py`의 셀렉터 맵에 등록한다.
